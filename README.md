# 街の通信簿 — OSS版

市区町村の比較画面を試す Next.js / TypeScript のプロトタイプです。表示する人口・価格・スコア・ハザード・気候は、デモ用の仮データです。実際の居住判断には使わないでください。

## 起動

```sh
npm ci
cp .env.example .env.local
npm run dev
```

環境変数を空のままにするとモックで動きます。トップ、`/m/[code]`、`/compare` が主な画面です。
`npm run build`、`npm run start` で本番形式の起動ができます。

## 実装の範囲

`src/lib/data.ts` がモックと型の正本です。
不動産情報ライブラリ・e-Stat・気象庁のクライアントは雛形で、集計処理には未実装部分があります。APIキーを入れるだけで実データ化が完了するわけではありません。
Supabase 用のスキーマ例は `supabase/migrations/` にあります。実運用のデータや接続先は含めていません。

## 実データを使う前に

取得・キャッシュ・再配布・出典表示の条件は、接続先の現行規約を確認してください。
このリポジトリには第三者APIの取得結果を同梱していません。ソースのMITライセンスは、将来取得するデータの再配布を許可するものではありません。

- [不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/)
- [e-Stat API](https://www.e-stat.go.jp/api/)
- [気象庁](https://www.jma.go.jp/)
